## Biggest changes

1. **Soul Tree rebuild + full refund (1.33.0)**
   - Existing Soul Tree ranks are refunded and lifetime points are recalculated.
   - Tree structure was redesigned with branches and 31 new perks.
   - Deep rows now cost more and are intended as longer-term goals.

2. **Rebirth reward model changed (1.33.1)**
   - Rebirth rewards now depend on whether the current life surpassed prior best progress.
   - Same-stage rebirth gives reduced payout; lower-stage rebirth gives further reduced payout.
   - The rebirth screen now explains which payout bracket applies.

3. **Realm-gated Soul Tree progression (1.33.1)**
   - Some high-end perks now require reaching specific realms (in any life) before ranks can be purchased.
   - Notably affects later **Unbroken Meridians** ranks.

4. **Core break became a major penalty (1.33.1)**
   - Gear above current realm is unequipped.
   - Remaining lifespan is forced to one day (24 years) until restored/reborn.
   - New **Scarred Core** debuff for the rest of that life: halved Qi generation and worst-tier stat-pill effectiveness.

5. **Crafting system overhaul (1.33.0)**
   - One shared slot pool across crafts (up to 6) instead of craft-specific bottlenecks.
   - Alchemy schools were rebalanced and existing players get one free school change.
   - Multiple crafting reliability fixes (stalled crafts, cycle payment behavior, tailoring experiment outputs, craft-time handling).

6. **Combat UX + flow changes (1.33.0)**
   - New default Ornate battle layout.
   - Faster foes now act first at hunt/round start (duels unchanged).
   - Added keybinds and better enemy readability (absorb/reflect/weakness indicators).

7. **Long-hunt risk system added (1.33.0)**
   - Extended uninterrupted hunting can trigger **misfortune** events (resource theft, knockouts, life-year loss, temporary stat weakening, etc.).
   - Encourages periodic breaks during automation/farming loops.

8. **Large QoL + bugfix wave (1.33.0)**
   - Patch notes call out over forty report-driven fixes and many UI/clarity improvements across market, rebirth, arrays, sect/family, drops and notifications.

## Practical impact for this guide

- Rebirth planning and Soul Tree point budgeting from pre-1.33 assumptions are no longer reliable without adjustment.
- Core-break handling is now high-priority risk management, not a minor setback.
- Crafting progression paths should assume shared slots and updated alchemy-school behavior.
- Extended AFK farming loops should account for misfortune risk.
