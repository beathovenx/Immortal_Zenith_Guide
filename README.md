# Immortal Zenith Guide

This project is a player-focused guide app for **Immortal Zenith**.

## Scope

This guide is reduced to two core features:

- World map tiers
- Soul Tree planner

## Open the guide locally

```powershell
npm.cmd start
```

Then open:

```text
http://127.0.0.1:4173
```

## Main sections

- [World map guide](guide/worldmap.md)
- [Soul Tree planner](app/soul-tree.mjs)
