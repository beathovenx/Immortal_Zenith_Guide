# Immortal Zenith Guide

This project is a player-focused guide app for **Immortal Zenith**.

## What this guide helps with

- Clear next steps for early and mid progression.
- Lightning path and Demonic/Yin path recommendations.
- Trait/manual lookup with practical notes.
- Qi Cap calculator and interpretation help.
- Attribute explanations in plain language.
- Reincarnation planning and Soul Tree priorities.
- Soul Tree planner (local planning in your browser).
- Dao Soul Point strategy.
- Fast progression route.
- World map tier reference.
- Patch highlights with the biggest gameplay changes.

## Open the guide locally

```powershell
npm.cmd start
```

Then open:

```text
http://127.0.0.1:4173
```
